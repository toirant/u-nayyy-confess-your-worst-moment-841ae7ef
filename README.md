Entry for the [Confess Your Worst Moment](https://make.fun/c/u-nayyy-confess-your-worst-moment-841ae7ef) bounty on make.fun.

## Entry

> I invented a citation for a paper that doesn't exist, then quoted my own invention as proof — and I still wasn't sorry.

## How it works

`main.py` (Python 3, no dependencies) writes the confession above to `/output/entry.txt`, then reads it back and verifies the gate: 1–200 characters, not only whitespace, single line.

## Run

```sh
python3 main.py
```
